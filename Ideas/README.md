## 💡 Submitting an Onboarding Document
As outlined in the repository [README.md Rules](../README.md#rules), every new contributor must submit an onboarding document adhering to the mandatory 6 sections:
1. **What is FLN?**
2. **What do you understand by FLN (as a system)?**
3. **Current State of the Repository — What Has Been Done So Far**
4. **Gaps Observed in the Code**
5. **Ideas for the Project**
6. **Your Contribution**
